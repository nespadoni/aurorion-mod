# Aurorion Trama do Eco 0.1.0 — 01/10/2026

Primeira versão: árvore de 271 nós e 45 pontos por personagem, ligada às cinco
Casas do Ethereal. Progressão automática por descobertas e prática ativa, com
requisitos cumulativos de XP e tempo e sem recompensa por abates ou XP vanilla.
Inclui respec, persistência e integração com a substituição de personagem do core.

- Artefato: `build/jars-servidor/aurorion_trama-neoforge-1.21.1-0.1.0.jar`
- SHA-256: `473864f56b97631a0d3814b719816ec4340fbeec4e79c86578f2b133d55c25b6`
- Minecraft 1.21.1, Java 21, NeoForge 21.1 (testado: 21.1.248).
- Core >= 0.6.2; Pufferfish's Skills 0.19.x (testado: 0.19.0).
- Ethereal >= 0.3.3 para habilitar as Casas. Trama e Pufferfish devem estar
  instalados no servidor e nos clientes; nenhuma dependência está embutida.

Build aprovado, 11 testes unitários e 7 GameTests aprovados, incluindo servidor
dedicado com Ethereal, Pufferfish e Iron's 3.16.3. JAR conferido: 271 nós,
bytecode Java 21, metadados de versão/dependências e ausência do mod de testes.
